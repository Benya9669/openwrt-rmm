                SECURITY / OWNERSHIP
                
Передача роутера

                
Новый владелец получит управление устройством. Текущие LuCI-сессии будут закрыты.

              

            

            

              
              
              
Последствия передачиУстройство исчезнет из текущего аккаунта; активный удалённый доступ будет закрыт согласно существующей серверной логике.

              
              

            

          


          

            

              
SECURITY / AGENT
Учётные данные агента
Плановая ротация проходит без разрыва мониторинга. Аварийный отзыв немедленно закрывает SSH и LuCI.

            

            

              
Ротация токенаНовый токен будет передан по текущему защищённому каналу и активируется после подтверждения агентом.

              
              
Аварийный отзывАгент потеряет доступ до повторной регистрации; активные туннели и ссылки будут закрыты.
