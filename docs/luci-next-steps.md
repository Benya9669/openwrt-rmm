# LuCI: исправления и следующие шаги

Зафиксировано 2026-10-01 после проверки установленной темы и dashboard 0.7.0.
Исходники пакетов находятся в отдельном репозитории `Benya9669/luci-theme-rmm`.
Этот документ сохраняет результаты аудита и предложения; реализация ещё не выполнена.

## Исправления перед следующим релизом

- [ ] P1: убрать буквальный `null` из четырёх карточек сводки. Проверить условные
  дочерние элементы native LuCI `E()`: локальный mock пропускает `null`, поэтому
  существующие проверки не воспроизводят этот дефект.
- [ ] P2: устранить наложение значков устройств LAN на странице «Интерфейсы» при
  ширине 320 px; сохранить подписи и доступность деталей устройств.
- [ ] P2: уплотнить схему сети: на 390 px она занимает около 880 px по высоте;
  на desktop остаётся много пустого пространства. Сохранить реальные связи и
  переходы к деталям, сделать второстепенные ветки сворачиваемыми.

## Шесть направлений развития (предложения)

1. **Настройка состава dashboard.** Выбор видимых блоков и их порядка, компактный
   режим и сброс к стандартному виду. Хранить предпочтения локально в браузере.
2. **Полезная сводка состояния.** WAN, память, Wi-Fi и агент в одном компактном
   блоке; показывать причину предупреждения, актуальность данных и переход к
   соответствующим деталям без повторяющихся пояснений.
3. **Графики с понятными масштабами.** Переключение доступного периода истории,
   единая подсказка RX/TX, отметки пропусков и сбросов счётчиков. Не обещать историю
   за час или сутки без отдельного механизма хранения; текущие данные ограничены
   временем наблюдения страницы.
4. **Обзор клиентов.** Единый компактный список проводных и Wi-Fi клиентов,
   поиск, сортировка и детали подключения. Явно различать DHCP lease, neighbour
   и подтверждённое подключение; не считать PHY-скорость фактическим трафиком.
5. **Навигация темы.** Подсказки и активные состояния иконок, доступное управление
   с клавиатуры, более компактное мобильное меню и поиск страниц с русскими
   синонимами. Сохранить штатные пути и контроль доступа LuCI.
6. **Проверки перед релизом.** Проверять native LuCI DOM на 320/390/768/1440 px,
   формы, модальные окна, фокус при обновлении, пустые и ошибочные состояния,
   русский перевод и контраст. Проверки и сборка пакетов — через GitHub Actions.

## Подтверждено аудитом

- Нет горизонтального переполнения dashboard на 320/390/768/1440 px.
- Работают детали роутера, SSID → клиент, сортировка и группировка клиентов.
- Работают стрелки на графиках; фокус сохраняется при автообновлении.
- В форме системы кнопка «Сохранить» видна; мобильные подписи выровнены влево.
- В журнале вкладки не обнаружены ошибки JavaScript.
- Настройки роутера в ходе проверки не менялись.

После исправлений повторить проверку на установленном пакете: локальный preview
не является достаточным подтверждением совместимости с native LuCI.
