## Приемка редизайна

- [ ] За 10 секунд видно, какие объекты требуют внимания.
- [ ] Причина проблемы понятна без raw JSON.
- [ ] LuCI открывается максимум за два клика.
- [ ] Диагностика запускается максимум за три клика.
- [ ] Обычный оператор не видит raw UCI и произвольные команды.
- [ ] Опасные действия требуют явного подтверждения.
- [ ] Основные сценарии работают на ширине 1366 px.
- [ ] Основные сценарии работают на ширине 1920 px.
- [ ] Основные сценарии доступны на мобильном экране.
- [ ] Ошибки API показываются понятным языком.
